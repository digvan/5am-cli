# IEDL visual gallery

113 examples · 106 local renders. This page renders directly on GitHub.

[Setup and rebuild](README.md) · [Interactive HTML](index.html) (open locally for sliders/search) · [Execution results](results.json)

Images below are actual saved renders. Open an image for a larger view; each example links to its editable recipe. Remote examples have no generated preview. These are capability demonstrations, not universal corrections.

**Local masks:** geometric masks and retouch coordinates were drawn for the concert example. Adapt them to each new photograph; they do not locate subjects automatically. Skin examples cover selected arm regions; sky and red-eye demonstrations need suitable targets.
